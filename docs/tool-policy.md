# 工具注册表与权限求值

`packages/tools/src/tool-catalog.data.json` 是 M3 工具与安全策略的数据源。它声明工具 ID/版本、副作用、风险等级、三种运行模式的自动放行与拒绝风险，以及必须审批的边界范围。

`ToolPolicyEvaluator` 固定按以下顺序求值：动作契约和工具注册表 → 显式拒绝 → 项目拒绝 → 工作区/秘密/平台边界 → 模式风险规则 → 审批或放行。显式拒绝不会因后续边界或模式规则而被覆盖。

`plan` 仅自动放行低风险操作；`work` 自动放行低、中风险的工作区操作；越出工作区、涉及秘密或平台边界的动作始终返回结构化审批请求。每个请求含 action、目标、风险原因、时间与可审计审批 ID。

文件工具使用工作区的真实根路径校验输入。读取返回内容 SHA-256 revision；写入和编辑必须携带该 revision，且写入会在目标同一目录内完成原子替换。符号链接或 junction 指向工作区外时会被拒绝。
