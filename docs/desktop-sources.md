# 桌面端来源联动

会话右侧“来源”面板由 runtime 的动作账本事件驱动。renderer 先记录 `action.planned` 中经过契约校验的动作 ID 与工具名，仅在同一 Run 的 `kb.search` 产生 `action.observed` 后接收知识库命中；它不会从助手正文猜测引用，也不会把网页或模型文本伪装成可信来源。

知识库检索结果携带 chunk ID、来源标题、URI、来源类型、分段序号、标签、入库时间、片段正文和检索分数。该结构在知识库边界由 `knowledgeSearchResultSchema` 校验，再作为不可信观察进入事件流。右侧卡片显示来源类型、标题、分段和片段预览；查询词命中时以设计系统的品牌弱色令牌高亮。点击卡片或助手回复下方的来源标注，会打开只读详情，展示完整片段与元数据。

来源标题、URI、标签、片段和查询词全部通过 `textContent`、文本节点与固定 SVG 模板渲染。来源内容不能注入 HTML、脚本、样式或审批界面，也不能修改权限和运行状态。新建会话会清空本地来源视图；知识库原始数据与审计事件仍由独立 runtime 持久化。
