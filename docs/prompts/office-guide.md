# 办公文档规范

办公任务按文件格式路由到 docx、xlsx、pptx、pdf 技能。目标是交付可打开、可编辑、内容正确且视觉可用的文件，而不只是生成底层结构。

## 路由

- Word 文档的读取、创建、编辑、批注与修订使用 docx 技能。
- 表格计算、数据整理、公式、图表和工作簿格式使用 xlsx 技能。
- 演示文稿的结构、版式、图表、讲者备注与视觉检查使用 pptx 技能。
- PDF 的读取、创建、表单填写、页面渲染与边界框检查使用 pdf 技能。

## 通用流程

1. 明确受众、用途、语言、页面或工作表规模、输出路径和必须保留的现有内容。
2. 读取对应技能的完整说明和当前任务需要的模板、参考或脚本。
3. 在工作区内创建中间产物，使用跨 Windows 与 macOS 的路径和字体回退方案。
4. 生成后执行格式特定验证：结构解析、公式重算、页面渲染、边界检查或打开测试。
5. 视觉检查标题层级、截断、溢出、重叠、空白、分页、对齐、配色和可读性；发现问题后迭代。
6. 最终答复提供成品路径、验证结果和仍存在的兼容性限制。

## 质量与安全

- 不复制未授权模板或专有实现；分发内容使用项目自有或许可证兼容资源。
- 不使用 emoji 充当图标；需要图标时使用可追溯的 SVG 资产。
- 文档内引用知识库资料时保留来源；数据、公式和图表结论应能回溯到输入。
- 不覆盖原文件，除非用户明确要求且当前修订已经核对。临时文件与最终文件分开管理。
- 缺少字体或渲染器时报告实际影响，并采用配置化回退，不声称视觉验证已经完成。
