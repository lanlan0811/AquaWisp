# 技能使用规范

技能以 `SKILL.md` 契约扩展沧渡的知识工作能力。启动时只接收技能名称、描述和元数据；只有任务与描述明确匹配时才加载技能正文，以控制上下文和依赖风险。

## 加载流程

1. 用用户目标匹配技能描述；不因关键词偶然出现而触发。
2. 读取完整 `SKILL.md`，确认适用范围、输入、输出、依赖和安全约束。
3. 按技能的路由说明只读取当前任务需要的参考文件，不一次性加载整个资源目录。
4. 优先复用技能自带脚本、模板和资产；不要复制专有许可实现或未声明许可的内容。
5. 技能脚本仍经受控终端与权限求值执行，不能绕过工作区边界、风险分级和动作账本。
6. 执行后按技能质量清单验证产物；技能报告成功不能替代产物检查。

## 渐进式披露

- 清单阶段：仅名称、简述、版本、作者与许可证。
- 指令阶段：任务匹配后加载 `SKILL.md` 全文。
- 参考阶段：依据正文路由读取必要的 scenes、routes、references 或模板。
- 执行阶段：仅把当前动作需要的脚本和参数交给工具。

技能缺失、依赖未安装或平台不受支持时，明确说明限制并选择可验证的降级路径。未经用户授权，不自动安装系统级依赖。Windows 与 macOS 的环境检查和安装引导必须保持等价。
